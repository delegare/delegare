# Delegare

> [Delegare](https://delegare.dev/) is an intent mandate API for AI agent payments and budget authorization. It allows agents to autonomously execute payments (like SaaS subscriptions or x402 data fetches) against pre-authorized spending mandates, without accessing underlying credit card details.

## Installation and Setup

To use the Delegare integration, install the `langchain-delegare` Python package:

```bash
pip install langchain-delegare
```

You'll need a Delegare Merchant ID and API Key to authorize operations. You can obtain these by creating a firm at [app.delegare.dev](https://app.delegare.dev).

Set them as environment variables:

```bash
export DELEGARE_MERCHANT_ID="your_merchant_id"
export DELEGARE_API_KEY="your_api_key"
```

## Tools

Delegare provides a suite of tools for agents to interact with payment mandates, check balances, and execute payments, particularly through the `DelegareToolkit`.

```python
from langchain_delegare import DelegareToolkit
from langgraph.prebuilt import create_react_agent

# Initialize the toolkit
toolkit = DelegareToolkit.from_env()

# Get all available tools
tools = toolkit.get_tools()

# Or instantiate a specific tool
from langchain_delegare import AuthorizePaymentTool
auth_tool = AuthorizePaymentTool(
    allowed_amounts_cents=[500, 1000] # Safe whitelist
)
```

For more detailed information, see the [Delegare Tools documentation](/docs/integrations/tools/delegare).

## Runnables and LCEL

For seamless data retrieval requiring x402 payment headers, you can use the `X402AutoPayRunnable` directly in your LCEL chains. It catches 402 errors, executes the required micro-payment via the intent mandate, and retries the fetch autonomously.

```python
from langchain_delegare import X402AutoPayRunnable

x402_fetcher = X402AutoPayRunnable(
    sync_client=toolkit.sync_client,
    async_client=toolkit.async_client
)

chain = x402_fetcher | prompt | model
```
