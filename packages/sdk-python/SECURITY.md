# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report any security vulnerabilities via email to \`security@securelend.ai\`.
We will acknowledge receipt within 48 hours, and we aim to provide a resolution or mitigation path within 14 days.

Please do **not** open a public issue on GitHub for security vulnerabilities.
