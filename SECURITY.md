# Security Policy

Delegare ships payment-authorization infrastructure used by AI agents to settle
x402 / MPP micropayments on behalf of buyers. Vulnerabilities in the SDKs,
middleware, or facilitator can expose funds, mandates, or credentials — we
take reports seriously and respond fast.

## Supported versions

Security fixes ship for the latest minor of each package. Older versions are
not patched; please upgrade.

| Package                  | Supported versions |
| ------------------------ | ------------------ |
| `@delegare/x402` (npm)   | `0.5.x` (current)  |
| `@delegare/sdk` (npm)    | `0.4.x` (current)  |
| `@delegare/mcp-tools`    | `0.4.x` (current)  |
| `delegare` (PyPI)        | `0.1.x` (current)  |
| `api.delegare.dev`       | Production         |

## Reporting a vulnerability

**Please do not open a public GitHub issue for vulnerabilities.** Use one of
the private channels below — we'll route, triage, and patch privately.

**Preferred:** GitHub Private Vulnerability Reporting.
→ https://github.com/delegare/delegare/security/advisories/new

**Email:** `security@securelend.ai` (PGP available on request).

What to include if you can:

- Affected component (package + version, or facilitator endpoint)
- Reproduction steps or a proof-of-concept
- Impact assessment (data exposed, funds at risk, scope)
- Suggested remediation (if any)

Source-to-sink traces with file paths and line numbers — like the report on
[#1](https://github.com/delegare/delegare/issues/1) — make our turnaround
materially faster. Strongly appreciated, not required.

## Our response commitment

| Stage                          | Target |
| ------------------------------ | ------ |
| Acknowledgment of report       | 48 hours |
| Initial triage and reproduction| 5 business days |
| Patch for critical severity    | 7 days |
| Patch for high severity        | 30 days |
| Patch for medium/low severity  | Next scheduled release |

A solo founder ships Delegare; if a critical report lands on a weekend, you
will hear back. If you do not hear back within 48 hours, please escalate by
re-sending to the email channel above with subject prefix `[ESCALATE]`.

## Coordinated disclosure

- We patch and ship before public disclosure of vulnerability details.
- Reporters are credited in release notes and the published GitHub Security
  Advisory unless they opt out.
- We do not currently run a monetary bug bounty, but we publicly acknowledge
  every confirmed report and will list contributors in any future bounty
  program at the highest tier earned.

## In scope

- `@delegare/x402`, `@delegare/sdk`, `@delegare/sdk-python`,
  `@delegare/mcp-tools` published packages
- `@delegare/openclaw-plugin`, `@delegare/langchain-delegare` SDK adapters
- `api.delegare.dev` — facilitator API (settlement, verification, mandate
  issuance, OAuth)
- `market.delegare.dev` — discovery surfaces
- `delegare.dev`, `delegare.co` — marketing and authenticated dashboards

## Out of scope

- Third-party dependencies — please report upstream and let us know so we can
  pin a fixed version
- Issues that require physical access to a buyer's device or social
  engineering of their wallet provider
- Volumetric DoS attacks (handled by AWS Shield / CloudFront)
- Self-XSS or issues requiring browser settings that disable the same-origin
  policy
- Reports generated by automated scanners without a working PoC

## Published advisories

- **2026-05-22** — Receipt-reuse via missing resource binding in
  `@delegare/x402` Case D. Patched in `@delegare/x402@0.5.20` + facilitator
  endpoint `POST /v1/x402/verify-receipt` enforcing resource / payTo / amount
  / TTL binding. Reported by @chenshj73. See
  [#1](https://github.com/delegare/delegare/issues/1).

## Cryptographic primitives

- AP2 mandates are SD-JWT-VC signed by `did:web:delegare.dev` (ES256). Public
  keys at https://api.delegare.dev/.well-known/jwks.json.
- On-chain settlement uses USDC EIP-3009 `receiveWithAuthorization` on Base
  mainnet. The facilitator never holds buyer or merchant private keys; it
  signs only the relayer transaction.
- Stripe fiat fallback uses Stripe Connect; Stripe owns risk and KYC.

Thank you for helping keep Delegare and its users safe.
