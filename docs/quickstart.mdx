---
title: Quickstart
description: Set up your first spending mandate in 5 minutes.
---

To start accepting agent payments with Delegare, you'll need to register as a Merchant and integrate our SDK.

### 1. Register as a Merchant
Currently, merchant registration is handled via our [Dashboard](https://app.delegare.dev). You will receive:
- `merchantId`: Your unique identifier.
- `apiKey`: Your secret key for authorizing session requests.

### 2. Request a Setup Session
When a user wants to enable payments for an agent, your backend creates a setup session.

```bash
curl -X POST https://api.delegare.dev/v1/mandates \
  -H "X-Delegare-Merchant-Id: your_merchant_id" \
  -H "X-Delegare-Api-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "maxPerTxCents": 1000,
    "maxMonthlySpendCents": 5000,
    "rail": "both"
  }'
```

This returns a `sessionToken` and a `setupUrl`.

### 3. Redirect the User
Send the user to the `setupUrl`. There, they will:
1. Connect their payment method (Stripe or Wallet).
2. Confirm the limits you requested.
3. Once finished, they are redirected back to your configured URL.

### 4. Collect the Intent Mandate
After the user completes setup, your agent can retrieve the **Intent Mandate** (a cryptographic SD-JWT-VC that proves authorization) from your backend. The Vault sends a webhook to your configured endpoint when the session is completed.

### 5. Charge the Mandate
Your agent can now execute payments directly using the Intent Mandate.

```bash
curl -X POST https://api.delegare.dev/v1/payments/charge \
  -H "X-Delegare-Merchant-Id: your_merchant_id" \
  -H "X-Delegare-Api-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "intentMandate": "eyJhbGciOiJFUz...",
    "amountCents": 500,
    "currency": "usd",
    "description": "API Subscription",
    "idempotencyKey": "unique_request_id_123"
  }'
```
