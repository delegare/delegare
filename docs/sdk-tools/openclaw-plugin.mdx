The official **Delegare** plugin for OpenClaw gives your AI agents the ability to autonomously execute payments and bypass `x402` paywalls.

By installing this plugin, your agent gains access to the Delegare tool suite, allowing it to spend funds safely using a pre-authorized **AP2 Intent Mandate (SD-JWT-VC)** without needing you to approve every transaction.

---

## 1. Installation

The Delegare plugin is a native OpenClaw extension. Install it directly using the OpenClaw CLI:

```bash
openclaw plugins install npm:@delegare/openclaw-plugin
```

## 2. Configuration & Security

OpenClaw has a very strict security model. By default, newly installed plugins and their tools are **not** exposed to your AI agents until you explicitly whitelist them.

You must update your OpenClaw gateway configuration (usually located at `~/.openclaw/openclaw.json`) to allow the plugin and its tools.

```json ~/.openclaw/openclaw.json
{
  "plugins": {
    "allow": ["delegare"]
  },
  "tools": {
    "allow": ["*"]
  }
}
```
*Note: You can replace `"*"` with the specific tool names like `"delegare_fetch"`, `"setup_spending_mandate"`, etc., if you prefer strict capability scoping.*

After updating the configuration, **restart your OpenClaw gateway**.

## 3. Authentication (OAuth)

Delegare uses OAuth 2.0 to securely issue your agent an Intent Mandate without exposing your master API keys to the OpenClaw environment.

1. Open the OpenClaw Web UI (e.g., `http://localhost:18789/__openclaw__/canvas/`).
2. Navigate to **Settings** (the gear icon) → **Auth**.
3. Find the **Delegare** provider in the list.
4. Click **Connect / Authenticate**.

You will be redirected to the Delegare Dashboard to connect your preferred payment method (Stripe card or Base USDC wallet) and set your agent's autonomous spending limits (e.g., "$50 max per month").

Once confirmed, you will be redirected back to OpenClaw, and the agent will be securely authorized!

## 🧪 Testing in the Sandbox

If you are developing a local e-commerce backend and want to test the plugin without using real money, you can configure the plugin to point to the Delegare Sandbox API.

Update your `~/.openclaw/openclaw.json` to include the `config` override:

```json ~/.openclaw/openclaw.json
{
  "plugins": {
    "allow": ["delegare"],
    "entries": {
      "delegare": {
        "enabled": true,
        "config": {
          "baseUrl": "https://api.sandbox.delegare.dev/v1"
        }
      }
    }
  },
  "tools": {
    "allow": ["*"]
  }
}
```

## Usage

Your agent is now economically enabled! Start a **new chat session** in OpenClaw (so it loads the updated tool context) and try prompting it with tasks that require payment or data retrieval:

<CodeGroup>
```text Agent Prompt
Fetch the data from https://premium-api.com/data. 
If it asks for payment via x402, use your mandate to pay it.
```

```text Agent Prompt
What is my current Delegare mandate balance?
```

```text Agent Prompt
Pay @coffee-shop $5.00 for the espresso order.
```
</CodeGroup>

## Security Features

*   **Zero Popups:** Once limits are set, the agent handles transaction signing server-side. No wallet popups will interrupt its workflow.
*   **Non-Custodial:** Your master private key never leaves your device. The agent only receives a tightly scoped, easily revokable session key.
*   **Strict Bounds:** Every transaction is verified by the Vault backend against the human-defined per-transaction and monthly limits.
